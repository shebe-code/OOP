# Object-Oriented Programming Demo

This repository is a small Python-based OOP example project. It demonstrates common object-oriented design patterns through simple domain models.

## Project structure

- `oop_project/models.py` — core domain classes
- `app.py` — an example script showing usage
- `tests/test_models.py` — unit tests for the models

## Run the demo

```bash
python app.py
```

## Run tests

```bash
python -m unittest discover -s tests
```
